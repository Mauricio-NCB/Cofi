Términos y Condiciones

Las presentes condiciones regulan el acceso y uso de este sitio web desarrollado como parte de un proyecto académico dentro de un Trabajo de Fin de Grado (TFG).

1. Objeto del sitio web

Este sitio web tiene como finalidad ofrecer una plataforma de ejemplo donde los usuarios pueden consultar eventos, participar en una comunidad mediante publicaciones y explorar diferentes actividades organizadas por categorías.

El acceso, navegación y utilización de esta web implica la aceptación de las presentes condiciones de uso.

2. Condición de usuario

Se considera usuario a cualquier persona que acceda, navegue o utilice el sitio web y sus contenidos.

Algunas funcionalidades pueden requerir registro previo en la plataforma.

3. Normas de uso

El usuario se compromete a utilizar el sitio web de forma responsable y conforme a la legislación vigente.

  • No realizar actividades ilícitas o contrarias al orden público.
  • No publicar contenidos ofensivos o que vulneren derechos de terceros.
  • No utilizar la plataforma para fines comerciales no autorizados.
  • No intentar acceder a zonas restringidas del sistema.

4. Funcionamiento del servicio

La plataforma permite a los usuarios consultar eventos, visualizar actividades según categorías y participar en un espacio comunitario mediante publicaciones.

Este sitio web forma parte de un entorno académico y algunos servicios pueden estar limitados o en fase de desarrollo.

5. Propiedad intelectual

Todos los contenidos del sitio web, incluyendo el diseño, código fuente, textos e imágenes forman parte de este proyecto académico y están protegidos por la normativa de propiedad intelectual.

Queda prohibida la reproducción total o parcial de los contenidos sin autorización.

6. Responsabilidad

El titular del sitio web no se hace responsable del uso indebido que los usuarios puedan hacer de los contenidos disponibles en la plataforma.

Tampoco se garantiza la disponibilidad permanente del sitio web, pudiendo producirse interrupciones por motivos técnicos o de mantenimiento.

7. Modificaciones

El titular del sitio web se reserva el derecho de modificar los contenidos y las presentes condiciones en cualquier momento.

8. Legislación aplicable

Las presentes condiciones se regirán por la legislación vigente aplicable en materia de servicios digitales y protección de datos.

Política de Privacidad

1. Recogida de datos

Este sitio web puede recopilar datos personales proporcionados voluntariamente por los usuarios al registrarse o interactuar con la plataforma.

Los datos recopilados pueden incluir información básica como nombre, correo electrónico o contenido publicado por el usuario.

2. Uso de la información

Los datos proporcionados se utilizarán exclusivamente para el funcionamiento de la plataforma y la gestión de las funcionalidades disponibles.

En el contexto de este proyecto académico, los datos no serán utilizados con fines comerciales ni cedidos a terceros.

3. Seguridad

Se adoptarán medidas técnicas razonables para proteger la información proporcionada por los usuarios y evitar accesos no autorizados.

4. Derechos del usuario

Los usuarios pueden solicitar la modificación o eliminación de sus datos personales en cualquier momento.

5. Finalidad académica

Este sitio web ha sido desarrollado exclusivamente con fines educativos como parte de un Trabajo de Fin de Grado y no constituye un servicio comercial real.
