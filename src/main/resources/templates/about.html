Sobre este proyecto

Esta plataforma ha sido desarrollada como parte de un Trabajo de Fin de Grado (TFG) con el objetivo de explorar el desarrollo de aplicaciones web modernas utilizando tecnologías como Spring Boot, Thymeleaf y Bootstrap.

La finalidad de esta aplicación es ofrecer un espacio para personas mayores, donde los usuarios puedan descubrir actividades, consultar eventos en un calendario y compartir publicaciones dentro de una comunidad.

Objetivo del proyecto

El objetivo principal es aplicar conocimientos adquiridos durante el grado en áreas como:

  • Desarrollo backend con Spring Boot
  • Diseño de interfaces web con HTML, CSS y Bootstrap
  • Gestión de datos mediante bases de datos
  • Arquitectura MVC en aplicaciones web
  • Desarrollo de una aplicación web usando metodología ágil

Aviso

Este proyecto tiene un propósito exclusivamente académico y no tiene fines comerciales ni ánimo de lucro. Los contenidos mostrados en la plataforma son de carácter demostrativo.
